WebGL Heatmap Overlay Demo

Continuous density via WebglHeatmapOverlay: GPU additive splats into a density buffer, then a LUT colorize pass every viewport frame. Home-zoom radius clamp keeps kernels from engulfing the slide when zoomed out.

What this shows

  • WebGL splat + colorize redrawn on every pan/zoom/rotate/flip (no settle debounce).
  • Screen-constant kernel size when zoomed in; radius shrinks past home zoom.
  • Three centroids (upper-left, upper-right, lower-left) for transform checks.
  • Viewport flip (OSD control / F), tiled-image flip, and rotation.

What this does not show

  • Toolkit FeatureCollection integration.
