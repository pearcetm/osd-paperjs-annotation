WebGL Feature Overlay Demo

Dense MultiPolygon rendering via WebglFeatureOverlay, with an optional Paper.js comparison on the same synthetic data. Pan, zoom, rotate, and flip to verify camera sync (viewport flip via the OSD control or F; tiled-image flip via the button below).

What this shows

  • Loading thousands of polygons into a WebGL overlay locked to the image.
  • Side-by-side comparison with the same geometry drawn in Paper.js.
  • Camera sync under pan, zoom, rotate, viewport flip, and tiled-image flip.
  • Debug triangle fill + stroke: stroke width with Paper-style rescale (screen px) vs image units.
  • Labels via Paper PointText (always on; WebGL-only still shows labels over WebGL geometry).

What this does not show

  • AnnotationToolkit properties.renderer: 'webgl' wiring.
  • Hit-testing or promote-to-Paper editing (those live on the toolkit path).
  • WebGL text rendering — use Paper for labels.
